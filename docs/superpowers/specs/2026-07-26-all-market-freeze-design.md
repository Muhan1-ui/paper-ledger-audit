# 体彩竞彩足球全玩法冻结与结算设计

## 目标

在纸面预测台账中，对每场具备可核验官方赛事编号、开赛时间、固定奖金和命名欧赔来源的竞彩足球比赛，同时冻结中国体彩的五个正式玩法，并在赛后以体彩官方开奖结果逐项结算和统计。

范围仅限公开数据的纸面监测、预测冻结和赛后复盘；不包含购票、投注、资金分配或任何资金操作。

## 范围与口径

每场合格赛事建立一个既有的胜平负主预测记录，并附加一个不可修改的全玩法快照。全玩法快照覆盖：

- 胜平负：胜、平、负。
- 让球胜平负：记录官方让球数及让胜、让平、让负。
- 比分：体彩全部标准比分选项及胜其它、平其它、负其它。
- 总进球：0、1、2、3、4、5、6、7+。
- 半全场胜平负：胜胜、胜平、胜负、平胜、平平、平负、负胜、负平、负负。

BTTS 保留为可选分析指标，不属于中国体彩竞彩足球正式玩法，不进入上述正式命中率报表。

## 冻结规则

1. 每个玩法保存完整的选项概率分布、最大概率选项、最大概率值、官方盘口或固定奖金（适用时）及来源链接。
2. 每个玩法无条件冻结一个最大概率选项，即使最大概率低于任何置信度阈值。低概率仅作为风险标签，不作为跳过或筛选条件。
3. 最大概率并列时使用稳定的预定义选项顺序决胜，并在记录中保留并列信息；统计不因并列而事后改选。
4. 冻结只能发生在开赛前。缺少官方让球数、必要固定奖金、完整模型输入或可追溯来源的玩法标记为 `skipped`，并记录原因，不生成可结算预测。
5. 已有历史胜平负预测与结算不修改、不倒填辅助玩法。全玩法统计从新结构启用后开始累计。

## 模型推导

以当前泊松比分矩阵为唯一的跨玩法概率来源，并与胜平负现有市场/模型融合结果保持可追溯关系：

- 让球胜平负：使用官方主队让球数，按调整后的比分聚合为让胜、让平、让负。
- 比分：将比分矩阵映射为体彩标准比分；矩阵之外的合法比分按胜其它、平其它、负其它聚合。
- 总进球：按总球数精确聚合为 0 至 6，余量聚合为 7+。
- 半全场：使用现有半场/全场代理分布聚合为九种官方选项。
- 胜平负：沿用现有融合后的三项分布，避免把辅助玩法反向覆盖主玩法。

## 账本结构

新增 `all_market_snapshot` 记录，引用既有冻结主预测的哈希，并包含赛事身份、冻结时间、各玩法快照及各玩法状态。新增 `all_market_settlement` 记录，引用该快照哈希，并包含体彩官方赛果链接、最终比分、各玩法官方彩果和逐项命中结果。

两类记录均使用现有内容哈希机制。结算只允许一次；任何一个缺失或无法由官方结果验证的玩法保留为未结算，不影响其他已验证玩法。

## 赛后结算

赛后从中国体彩页面的“开奖结果”模块读取五类彩果。结算流程验证：

1. 官方来源链接为 HTTP(S) 且与赛事编号匹配。
2. 比分、胜平负、让球、总进球、半全场之间彼此一致。
3. 每个预测最大项与对应官方彩果精确比较，写入命中或未命中。

若官方页面未显示某项彩果，则该项标记为 `pending`，不得使用第三方页面代替。

## 报表

报表按玩法独立输出：冻结场次、可结算场次、跳过数、命中数、命中率、平均最高概率、Brier 分数和 Log Loss（完整概率分布可用时）。

在样本少于 50 场前，所有指标均标为描述性观察；不得用于模型调参。达到 50 场后才提供正式校准指标，达到现有调参门槛后才允许时间切分评估。

## 测试与验收

- 单元测试覆盖每个玩法的概率归一化、最高项选择、并列规则、比分映射与边界聚合。
- 验证器拒绝开赛后冻结、缺少官方让球数、缺少选项、重复结算、错配赛事和被篡改哈希。
- 端到端测试使用固定的官方结果样本，确认五类玩法独立结算且报表分母正确。
- 旧账本可正常读取，旧记录只在胜平负报表中统计，不被伪造为全玩法样本。
