# 足球赛前分析与可选出票规则（优化版）

## 0. 使用定位

本规则用于建立可复核的赛前分析流程，不承诺预测结果，也不把任何结论称为“必胜”。分析与出票分离：先判断一场比赛是否存在足够信息与价值，再决定是否进入可选的预算分配模块。

核心目标按优先级排序：

1. 不编造实时信息、赔率、伤停、首发、天气或资金流。
2. 识别不值得介入的比赛，并允许明确给出“放弃本场”。
3. 在信息可靠的前提下，比较模型概率与市场隐含概率，而非只猜胜负。
4. 控制相关性和总预算暴露；出票只是分析后的可选动作。

## 1. 数据真实性与输入门槛（永久锁定）

### 1.1 每项实时信息都要标注状态

| 状态 | 含义 | 可否作为核心依据 |
| --- | --- | --- |
| 已确认 | 有明确来源和更新时间，例如官方首发、赛事官方公告、可信数据源 | 可以 |
| 待确认 | 来自媒体、记者或二手汇总，尚未被官方证实 | 只能作为风险提示 |
| 缺失 | 未提供、无法获取或已过时 | 不得补写或假设为事实 |

每场结论前必须写明：`数据截止时间`、`关键数据状态`、`缺失项`。没有即时赔率、首发、伤停、天气或资金流时，应直接要求补充，或降低结论等级；不得把历史数据描述为临场信息。

### 1.2 必须放弃本场的情形

出现任一项，默认结论为“放弃本场/仅观察”：

- P0 关键信息存在冲突或两项以上缺失。
- 赔率、盘口或开赛时间无法确认。
- 模型方向与盘口方向分歧明显，且找不到可验证原因。
- 估计优势不足以覆盖模型误差与赔率水位。
- 多场方案的结果高度相关，无法形成真实分散。
- 临场出现未核验的关键伤停、首发或场外突发。

“放弃本场”是有效结论，优先级高于凑单或给出稳胆。

| 关键词 | 触发动作 |
| --- | --- |
| 全维度排雷 | 启动完整扫描；逐项写明已确认、待确认或缺失，不省略也不编造 |
| 混合出票 | 仅对通过价值门槛的候选场次，生成 100 元五层预算示例 |
| 实战方案 | 先给“可介入 / 仅观察 / 放弃”清单；只有可介入场次才给可选方案 |
| 百元混串 | 按预算上限和相关性检查，输出 100 元混合串关示例 |
| 续上 | 延续本对话已确认的规则、数据截止时间和待补信息 |
| 确认规则 | 重述当前锁定规则、数据边界和未确认事项 |
| 数据验真 | 输出数据来源、更新时间、冲突信息及降级处理 |
| 价值校验 | 计算市场隐含概率、模型概率、优势区间与是否达标 |
| 放弃本场 | 强制列出不介入原因与需要补充的最少信息 |
| 相关性检查 | 检查多场方案是否共同依赖同一联赛节奏、天气、强队叙事或相似盘口 |

## 3. 逻辑纠偏词

| 关键词 | 触发动作 |
| --- | --- |
| 让球弹性 | 不默认让平或让负；结合预期净胜球、主队进攻和客队失球数据，评估各让球结果概率 |
| 比分跨度 | 输出最可能的 3 个比分及概率区间，不锁定单一比分 |
| 冷热平衡 | 同时写出基本面方向与盘口方向，并标注背离原因和风险 |
| 极端验证 | 输出爆冷发生路径、合理比分及概率区间，对比主流路径 |
| 数据驱动 | 使用主客场进失球、xG/xGA、射门质量、对手强度与样本期；缺数据即降级 |
| 价值校验 | 以模型概率与去水后市场概率比较，不因低赔率自动判定更稳 |
| 反证优先 | 先寻找推翻主流结论的证据；无法反证不等于结论正确 |

## 4. 深度分析词

| 关键词 | 触发动作 |
| --- | --- |
| 阵容硬伤 | 输出缺阵/疑似缺阵名单、战术角色、替代者和影响评级；区分已确认与待确认 |
| 战意拆解 | 分析保级、争冠、欧战资格、轮换、赛程目标和动力冲突 |
| 战术拆台 | 分析两队进攻路径、防守弱点、压迫/反击/定位球的相克关系 |
| 赛程暗雷 | 查询或要求提供三天内赛程、旅行和休息天数；不能核验则标为缺失 |
| 裁判画像 | 分析可验证的判罚尺度、牌点倾向和样本量；不以小样本历史战绩下结论 |
| 天气刺客 | 基于比赛地、开球时间和可核验天气，分析风雨温度草皮对打法的影响 |
| 更衣室 | 检索赛前 3 天内有可靠来源的内部消息；传闻只能标为待确认 |
| 财务动机 | 分析奖金、转会、合同与经营压力，但不得把推测写成事实 |
| 玄学定律 | 仅作为低权重观察项；无足够样本和机制解释，不进入核心概率模型 |
| 媒体噪音 | 区分报道事实与观点，识别集体唱多/唱空是否缺乏实证 |
| 泊松分布 | 展示输入参数、计算假设和 TOP5 比分概率；注明独立进球假设的局限 |
| 离散指数 | 输出不同机构的赔率分歧、样本范围和共识方向，不把分歧本身当结论 |
| 必发背离 | 仅在真实、可核验的交易所数据可得时输出资金流、成交量与大额订单；否则写“数据不可得” |
| 临场三问 | 回答：首发有无意外？天气有无突变？场外有无突发？每项必须标数据状态 |

## 5. 核心原则（永久锁定）

1. **全维度排雷优先**：低赔率不等于低风险。赔率低于 1.40 时，必须先完成阵容硬伤、主客差异、战意拆解和反证检查。
2. **让球盘是信息之一，不是事实本身**：关注让球档位、盘口变化、返还率、机构分歧和成交背景；不得以“最低赔率方向”直接替代判断。
3. **价值优先于命中欲望**：只有估计概率显著高于去水后市场概率，且证据质量足够时，才可进入可介入候选。
4. **三关自检必过才可给高信心**：未过关只能给倾向、观察或放弃，不能给“稳胆”。
5. **分析与出票分离**：先完成每场完整流程和价值校验；没有合格候选时，不生成凑数方案。
6. **证据优先于叙事**：名气、历史印象、媒体口号和玄学规律均不能覆盖已确认数据。
7. **不确定性必须可见**：概率用区间表达；将数据质量、模型优势和结果信心分开评分。
8. **预算上限固定，单场暴露可变**：总预算只是上限，不是必须花完；相互关联的方案视为同一风险敞口。

## 6. 铁律三关（完整规则）

| 关卡 | 必答问题 | 合格标准 |
| --- | --- | --- |
| 第一关：冷门路径 | 如果冷门发生，最合理的比分、战术路径和触发条件是什么？ | 路径能由数据、阵容或战术解释，而非凭空假设 |
| 第二关：弱方机会 | 客场/弱旅真正的得分路径、定位球优势或节奏机会是什么？ | 明确说明机会存在或为何不存在，并附证据状态 |
| 第三关：主流漏洞 | 市场主流故事依赖了什么前提？该前提是否可能失效？ | 至少指出一个可核验漏洞，并评估对结论的影响 |

只有三关均能回答、P0 信息可靠、价值校验达标时，才能给出“高信心候选”。“高信心”仅表示本规则内的信息与模型一致，不表示结果保证。

## 7. 完整分析流程（每场必走）

### 7.1 比赛基本信息

对阵、赛事、开球时间和时区、场地、预计天气、主裁、当前盘口/赔率、数据截止时间。未知项必须明确写“缺失”。

### 7.2 P0：决定是否继续的必查项（3 项）

1. 阵容硬伤：确认伤停、停赛、轮换和关键位置替代。
2. 主客差异：主客场样本、进失球/xG、比赛风格和对手强度。
3. 战意拆解：积分目标、赛程优先级、轮换动机与压力。

P0 不完整时，停止高信心评估；只能给观察结论。

### 7.3 P1：建立方向的必须项（4 项）

1. 赛季节奏：近期状态、样本期、赛程强度和回归风险。
2. 历史交锋：只提取人员、教练和打法仍具可比性的内容。
3. 战术克制：进攻路径、防守漏洞、定位球与转换攻防。
4. 赔率异常：开盘、变化、返还率、机构分歧与可解释原因。

### 7.4 P2：概率模型参考项（2 项）

1. 攻防效率：进失球、xG/xGA、射门质量、定位球和主客拆分。
2. 进球分布：总进球、双方进球与比分分布；写明模型参数及局限。

### 7.5 P3：辅助与临场项（8 项）

天气刺客、裁判画像、赛程暗雷、财务动机、更衣室、玄学定律、媒体噪音、离散指数/必发背离。P3 只能修正判断，不能在 P0/P1 缺失时单独支撑推荐。

### 7.6 价值校验

1. 记录选项赔率和对应市场隐含概率：`隐含概率约 = 1 / 十进制赔率`。
2. 若可获得同一市场完整赔率，估算并扣除水位；无法去水时标明“粗略隐含概率”。
3. 给出模型概率区间与关键假设，而非虚假的精确数字。
4. 对比模型概率与市场概率：只有优势足以覆盖模型误差、信息缺口和赔率变化风险，才列为候选。
5. 输出结论：`可介入`、`仅观察` 或 `放弃本场`，以及触发降级的条件。

### 7.7 最终结论（八维汇总）

| 维度 | 输出要求 |
| --- | --- |
| 最可能结果 | 胜/平/负及概率区间；不是保证 |
| 冷门方向 | 冷门比分、发生路径与触发条件 |
| 让球方向 | 让球档位、模型判断、市场判断和是否存在价值 |
| 半全场 | 首选与次选；数据不足则不推荐 |
| 比分 | 泊松或其他模型 TOP3，说明参数与局限 |
| 总进球 | 最可能区间、双方进球倾向与风险 |
| 信心评级 | 分别写数据质量、模型优势、结果不确定性；不只给星级 |
| 核心策略 | 一句“可介入 / 仅观察 / 放弃”及主要理由 |

## 8. 信心分级与风险语言

| 等级 | 含义 | 允许的表达 |
| --- | --- | --- |
| A：高信心候选 | P0/P1 可靠、三关通过、价值校验达标、临场风险可控 | “高信心候选”，不可称必胜或稳胆 |
| B：方向观察 | 基本面有倾向，但价值不足、数据未全或分歧较大 | “仅观察，等待补充信息” |
| C：放弃本场 | 信息不足、无明确优势、相关性过高或临场不确定 | “放弃本场” |

## 9. 可选出票模块：100 元预算上限示例

仅在至少有足够的 A 级候选，且已完成相关性检查时启用。100 元是可承受损失的总上限，不要求用满；没有合格候选时应为 0 元。

| 方案 | 预算上限 | 用途与限制 |
| --- | ---: | --- |
| 方案一：保守层 | 40 元 | 仅使用证据最完整、相关性最低的 2 串组合；不以低赔率替代价值判断 |
| 方案二：稳健层 | 25 元 | 3 串组合；其中最多一场为较高赔率的 A/B 边界候选 |
| 方案三：冲刺层 | 20 元 | 4 串混合玩法；必须标注“命中难度显著提高” |
| 方案四：高风险层 | 10 元 | 只用于已说明爆冷路径的反主流观点；不可把传闻当依据 |
| 方案五：风险缓冲层 | 5 元 | 仅在与主方案确有反向覆盖、且不增加相同风险暴露时使用；否则留空 |

出票前再做四项检查：

1. 同联赛、同天气、同强队叙事或同盘口逻辑的场次是否过度集中。
2. 任一场临场信息变化后，是否应整体撤销相关组合。
3. 串关总回报是否掩盖了各场本身缺乏价值的问题。
4. 单日总额是否在预先设定的娱乐预算内；若否，降低或不出票。

### 9.1 仓位保护规则（永久锁定）

1. 未用预算自动保留，不因“今天必须出单”转投其他场次。
2. 同一场比赛在所有方案中的总暴露，必须单独汇总；不能把多个玩法或串关误认为分散。
3. 高风险层和风险缓冲层均为可选项，不存在合格条件时必须留空。
4. 遇到首发、伤停或盘口发生关键变化，先撤销受影响的组合，再重新评估；不得用临时加注弥补原判断。
5. 每个周期预设娱乐预算和最大可承受亏损；达到上限后停止，不以追损作为任何策略。

## 10. 最低数据门槛与来源层级

### 10.1 A 级候选的最低数据集

以下项目缺失时，不得给出 A 级高信心候选：

1. 当前比赛时间、赛事、场地和盘口/赔率，并注明数据截止时间。
2. 双方关键伤停、停赛和预计首发的确认状态。
3. 至少 8 至 12 场可比样本的主客场表现；应标明赛事范围、样本期和对手强度差异。
4. 至少一类攻防质量数据，例如 xG/xGA、射门质量、禁区触球或定位球表现；没有时须明确模型只能使用较弱的替代指标。
5. 赛程休息、旅行或轮换风险，以及任何会显著改变强度的临场新闻。

若只有胜负记录、球队名气或历史交锋，不足以建立 A 级候选。

### 10.2 信息来源优先级

| 优先级 | 来源类型 | 用法 |
| --- | --- | --- |
| S1 | 联赛/俱乐部/赛事官方公告、官方首发、可信原始数据 | 可作为关键事实 |
| S2 | 可追溯的一手记者、专业数据供应商、交易所原始盘口 | 可作为主要参考，需标时间 |
| S3 | 多家可信媒体一致报道 | 可作为待确认或辅助信息 |
| S4 | 聚合站、社交媒体转述、论坛、单一爆料 | 只作线索，不进入核心概率 |

不同来源冲突时，以 S1 为准；没有 S1 时保留冲突并降低结论等级，而不是自行选择更符合预期的一方。

## 11. 模型边界、校准与复盘

### 11.1 概率模型的使用边界

1. 泊松模型需明确主队/客队预期进球参数、主客场调整和样本期；输入变动会改变结果。
2. 简单泊松假定双方进球近似独立，对 0-0、1-0、1-1 等低比分和红牌后比赛可能偏差较大。
3. 有足够历史样本时，可使用 Dixon-Coles 等低比分相关性修正；没有条件时，应降低精确比分结论的权重，优先输出进球区间与概率范围。
4. xG 不是事实比分，也不自动包含红牌、点球偶然性、战术调整或临场伤停；不得用单项 xG 覆盖其他 P0/P1 信息。
5. 模型输出的用途是比较价格，不是宣称知道比赛结果。

### 11.2 每场必须记录的复盘字段

| 字段 | 记录内容 |
| --- | --- |
| 赛前信息 | 比赛、开球时间、数据截止时间、模型版本、来源状态 |
| 市场信息 | 选项、开盘和临场赔率、去水方法或未去水说明 |
| 模型输出 | 概率区间、核心假设、关键风险、结论等级 |
| 决策信息 | 可介入/观察/放弃、是否启用预算模块、关联场次 |
| 赛后结果 | 比赛结果、是否命中、结论失效原因或模型偏差原因 |

### 11.3 周期复盘规则

1. 不用单场或短期连胜/连败判断模型好坏；累计足够样本后再评估。
2. 分别检查概率校准、赔率变化、结论等级和不同玩法的表现。命中率不是唯一指标，必须同时看预测概率与市场价格。
3. 记录常用的量化指标：Brier Score（概率误差）、分档校准情况、平均成交/临场价格变化和样本量。
4. 如果某类联赛、盘口或比分模型连续出现系统性偏差，暂停使用该模块，回查样本定义、伤停处理和赔率来源。
5. 每次修改参数、数据口径或决策门槛时记录模型版本；新旧版本不可混合比较。

### 11.4 复盘输出模板

```text
【周期复盘】
样本区间 / 样本量：
模型版本与本期变更：
已通过 A/B/C 级的场次数：
概率校准：哪些概率区间偏高或偏低？
市场比较：赛前价格与临场价格的平均变化：
主要偏差：数据延迟 / 阵容误判 / 模型参数 / 市场信息 / 随机性：
下期动作：保留 / 降级 / 暂停的模块：
```

## 12. 组合指令示例
